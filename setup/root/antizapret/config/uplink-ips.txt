# Добавление IP-адресов и подсетей для маршрутизации через зарубежный сервер (аплинк)
#
# То же, что uplink-hosts.txt, только для адресов, у которых нет домена или чей домен
# резолвится во что-то другое. Всё остальное из списков АнтиЗапрета идёт через WARP
#
# Формат записи: 192.0.2.0/24
# Где:
#   192.0.2.0/24 - IPv4-адрес или подсеть в формате CIDR, маска обязательна
#
# Примеры записи:
#   192.0.2.10/32  - один адрес
#   192.0.2.0/24   - подсеть целиком
#
# Этот список имеет приоритет над IP-списками АнтиЗапрета
# Если адрес есть и здесь, и там - он пойдет через зарубежный сервер
#
# Адреса отсюда попадают и в маршруты клиента, иначе трафик до них не дошел бы до сервера.
# После правки: /root/antizapret/parse.sh ip
#
# Строки начинающиеся с # это комментарии и они не обрабатываются
#
